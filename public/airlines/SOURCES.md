# Airline logo sources

These assets reproduce the airlines' existing branding. They are presented to identify the real airlines represented by the virtual group, rather than to imply that this website is an official airline website.

## Shared China Southern branding

China Southern Henan Airlines, Guizhou Airlines, Zhuhai Airlines, and Shantou Airlines use the shared China Southern logo asset. A separate logo variant has not been invented for these subsidiaries. China Southern's annual report explains that its businesses outside XiamenAir and Chongqing Airlines operate under the China Southern name and kapok emblem.

- Official group membership: https://www.csairgroup.cn/cn/cpyfw2/index.html
- Official annual report, "Intellectual Property": https://www.csair.cn/en/about/investor/qitabaogao/2023/resource/ea7fa4af230785b93e6371f5d2874a22.pdf
- Official visual identity explanation: https://www.csairgroup.cn/cn/gywm3/qywh92/viyy47/index.html

China Southern Cargo also uses the shared China Southern logo asset. Its official cargo website displays that same emblem and China Southern Airlines wordmark. The website card's separate CARGO badge identifies the cargo carrier without altering the official logo.

- Official cargo website: https://cargo.csair.com/pages/home
- Official header stylesheet: https://cargo.csair.com/css/common-new.css
- Official header sprite: https://cargo.csair.com/images/index/icons-sprites.png
- Published sprite region: `.bg-csair_logo`, left 209 px, top 10 px, width 220 px, height 40 px.

Sources verified on 4 October 2026.

## Local image files

The section now serves all logos locally. Existing image references have been
reused where available; no logo artwork or airline-specific variants were drawn.
SVG files retain the original vector paths with export comments/metadata removed.
Raster logos use lossless WebP encoding with preserved aspect ratios and alpha.
Jiangxi's previous SVG was a raster image wrapper, so its embedded image is
served directly as WebP.
